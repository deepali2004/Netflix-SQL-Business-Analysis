# 🎬 Netflix SQL Business Analysis

> SQL-based analysis of Netflix movies and TV shows using MySQL.

This project explores Netflix's content catalog using SQL to answer
15 business-driven questions related to content types, ratings,
countries, genres, actors, directors, release years, and content trends.

## 📊 Project Overview

The analysis focuses on understanding Netflix's content library through
SQL queries and business-oriented questions.

### Key Areas Analyzed

- 🎥 Movies vs TV Shows
- ⭐ Content ratings
- 🌍 Countries with the most Netflix content
- 📅 Release-year trends
- 🎬 Directors and actors
- 📺 TV shows with multiple seasons
- 🎭 Genres and documentaries
- 🔎 Content descriptions and keyword analysis

  ## 💡 Business Questions

The project answers 15 business questions, including:

1. What is the distribution of Movies vs TV Shows?
2. What are the most common ratings?
3. Which movies were released in 2020?
4. Which countries have the most content?
5. What is the longest movie?
6. What content was added in the last five years?
7. Which titles were directed by Rajiv Chilaka?
8. Which TV shows have more than five seasons?
9. Which genres have the most content?
10. What are the yearly content trends in India?
11. Which movies are documentaries?
12. Which titles don't have a listed director?
13. How many movies feature Salman Khan?
14. Which actors appear most frequently in Indian movies?
15. How can content be categorized using keywords such as "kill" and "violence"?

  ## 📈 Key Insights

- Movies make up the majority of Netflix's content library.
- The United States and other major markets contribute significantly
  to Netflix's content catalog.
- Netflix's content library has expanded considerably across recent years.
- A significant portion of titles contain multiple genres and cast members.
